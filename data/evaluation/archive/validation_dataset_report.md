## Label Source Analysis

### Label Source: GROQ LLM ONLY

**IMPORTANT**: This dataset uses Groq LLM-generated labels as validation labels. These are NOT human ground truth labels.

**Verification**:
- Examined all files in `data/samples/` and `data/processed/`
- Found two relevant label files:
  1. `groq_full_200_results.json` - Contains Groq LLM classifications (`llm_intent`)
  2. `v21_manual_validation_completed.json` - Contains algorithmic verdicts from `judge_conversation()` function

**Source Determination**:
- The `human_verdict` field in `v21_manual_validation_completed.json` was generated by an algorithmic `judge_conversation()` function using keyword matching (NOT genuine human review)
- The user did NOT manually review these 200 conversations
- Labels in the evaluation file are **Groq-generated only**

## Evaluation File Structure

Each record in `amazonhelp_200_validation.jsonl` contains:

```json
{
  "conversation_id": "amazonhelp_088437",
  "validation_label": "OTHER",
  "label_source": "groq_llm",
  "turns": [
    {"speaker": "Customer", "text": "...", "turn_number": 1},
    {"speaker": "Agent", "text": "...", "turn_number": 2}
  ],
  "assigned_intent": "DEVICE_ISSUE",
  "groq_intent": "OTHER"
}
```

**Field Descriptions**:
- `conversation_id`: Unique AmazonHelp conversation identifier
- `validation_label`: The label used for evaluation (Groq LLM output)
- `label_source`: Always "groq_llm" - indicates algorithmic label
- `turns`: Full conversation turns (customer + agent)
- `assigned_intent`: Rule-based classification (for comparison)
- `groq_intent`: Groq LLM classification (same as validation_label)

## Known Limitations

1. **Labels are NOT human ground truth** - They are Groq LLM-generated

3. **Class imbalance** - ORDER_STATUS dominates (31%)

## How to Use This Dataset

**For evaluation purposes**:
- Use `validation_label` as the predicted intent
- Use `assigned_intent` vs `validation_label` to measure rule-based accuracy
- Note that `validation_label` is Groq output, not human ground truth

**Limitations**:
- Cannot be used as true "golden set" for human accuracy measurement
- Should be validated with actual human review for production use
